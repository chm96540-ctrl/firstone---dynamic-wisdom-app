# Guitar Tuner

A simple chromatic guitar tuner that installs on your phone like an app.
It uses your microphone, shows how sharp or flat you are, plays reference
tones for standard tuning (E A D G B e), keeps the screen on while tuning,
and works offline once it's installed.

## Put it online (one time)

1. On GitHub, open this repository → **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*,
   pick the branch with these files and the `/ (root)` folder, then **Save**.
3. After a minute GitHub shows the address, e.g.
   `https://<your-username>.github.io/<repo-name>/`.

## Install on your phone

- **iPhone (Safari):** open the address → Share button → **Add to Home Screen**.
- **Android (Chrome):** open the address → ⋮ menu → **Install app**
  (or **Add to Home screen**).

Open it from the home-screen icon, tap **Start tuner**, and allow the microphone.
